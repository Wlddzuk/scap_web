Privacy Policy

60s Science Studio — Last updated: 18 July 2026

1. Overview

60s Science Studio ("the App") is a personal, single-operator tool that publishes videos to the Operator's own TikTok account. It has no public user base and does not collect personal data from anyone other than the Operator's own TikTok account authorization.

2. Data the App stores

  • TikTok OAuth tokens for the Operator's own account, stored locally on the Operator's private server and used only to upload videos to that account.
  • Basic account information returned by TikTok's API (such as display name and posting eligibility), used only to confirm the connected account and complete uploads.
  • Generated media (video files, scripts, and article summaries) created by the Operator's own pipeline.

3. What the App does NOT do

  • It does not collect data about any TikTok user other than the Operator's own account.
  • It does not sell, share, or transfer data to third parties.
  • It does not use tracking, advertising, or analytics services.

4. Data retention and deletion

OAuth tokens can be revoked at any time by the Operator from TikTok's connected-apps settings, and local tokens can be deleted by removing the App's token file. Generated media is retained only on the Operator's own systems.
